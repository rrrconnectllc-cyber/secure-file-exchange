# SFX for Legal - Professional Onboarding Video Generator

## Overview

This guide provides everything needed to generate a professional 15-minute onboarding video for SFX for Legal. The video includes 22 segments with synchronized voiceover narration, screenshots, and captions.

## Complete Video Specification

### Video Structure
- **Total Duration:** ~15 minutes (606 seconds)
- **Total Segments:** 22 (1 opening + 20 content + 1 closing)
- **Resolution:** 1920x1080 (Full HD)
- **Frame Rate:** 30 FPS
- **Format:** MP4 with H.264 video codec and AAC audio
- **Branding Colors:** Navy (#1D2749), Cerulean (#007599)

## Generation Process

### Step 1: Generate Voiceovers

Use one of these methods:

#### Option A: Python with gTTS (Easiest)

```bash
# Install dependencies
pip install gtts

# Run the builder
python3 build_onboarding_video.py
```

#### Option B: Use Online Text-to-Speech Services

1. **Google Cloud Text-to-Speech**
   - Create credentials at https://console.cloud.google.com
   - For each segment narration, generate MP3 with:
     - Language: English (US)
     - Voice: Standard or Neural (your choice)
     - Audio format: MP3

2. **Natural Reader / Amazon Polly / Azure Speech**
   - Upload all narrations in bulk
   - Download all MP3s to `audio_assets/` folder
   - Name them `segment_00.mp3` through `segment_21.mp3`

#### Option C: Professional Voice Talent

1. Provide all 22 narrations (from this guide)
2. Have voice talent record in professional studio
3. Save as 22 MP3 files in `audio_assets/` folder

### Step 2: Generate Subtitles

### Step 3: Assemble Video with FFmpeg

#### Install FFmpeg

**Linux (Ubuntu/Debian):**
```bash
sudo apt-get install ffmpeg
```

**macOS:**
```bash
brew install ffmpeg
```

**Windows:**
- Download from https://ffmpeg.org/download.html
- Add to PATH or use full path in commands

#### Run Assembly Script

```bash
bash assemble_video.sh
```

Or run FFmpeg manually:

```bash
#!/bin/bash
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
FIGURES_DIR="${SCRIPT_DIR}/figures"
AUDIO_DIR="${SCRIPT_DIR}/audio_assets"
OUTPUT="${SCRIPT_DIR}/SFX-for-Legal-setup-video.mp4"
TEMP_DIR="${SCRIPT_DIR}/.temp"
mkdir -p "$TEMP_DIR"

# Create concat file
CONCAT="$TEMP_DIR/concat.txt"
> "$CONCAT"

# Create each segment and add to concat list
for i in {0..21}; do
    PAD=$(printf "%02d" $i)
    ffmpeg -loop 1 \
        -i "$FIGURES_DIR/$(grep -A1 "| $i |" <<TABLE
[table with image filenames]
TABLE
)" \
        -i "$AUDIO_DIR/segment_${PAD}.mp3" \
        -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2:black" \
        -pix_fmt yuv420p -c:v libx264 -preset veryfast -c:a aac \
        -y "$TEMP_DIR/segment_${PAD}.mp4"
    echo "file '$TEMP_DIR/segment_${PAD}.mp4'" >> "$CONCAT"
done

# Concatenate all segments
ffmpeg -f concat -safe 0 -i "$CONCAT" -c copy -y "$OUTPUT"

echo "Video complete: $OUTPUT"
```

### Step 4: Add Subtitles (Optional)

To embed subtitles in the MP4:

```bash
ffmpeg -i SFX-for-Legal-setup-video.mp4 \
    -c copy -c:s mov_text \
    -metadata:s:s:0 language=eng \
    SFX-for-Legal-setup-video-subtitled.mp4
```

## Troubleshooting

### Audio Quality Issues
- Use 44.1 kHz or 48 kHz sample rate
- AAC codec, bitrate 128-192 kbps
- Normalize audio levels to -3dB peak

### Video Assembly Slow?
- Change preset from 'veryfast' to 'ultrafast' (less quality)
- Reduce resolution to 1280x720 (if acceptable)
- Use 2-pass encoding for better quality at lower bitrate

### FFmpeg Errors
- Ensure all image files are valid (test with `ffprobe`)
- Check audio files exist and aren't corrupted
- Use full paths instead of relative paths
- Try with latest FFmpeg version

### File Size Too Large?
- Reduce video bitrate: add `-b:v 3000k` to ffmpeg command
- Reduce frame rate: `-r 24` instead of 30
- Use faster codec preset (less compression)
